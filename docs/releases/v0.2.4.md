# @orizz-rs/ui v0.2.4

## ERP form controls and composition primitives

This release expands the form foundation for ERP workflows with 11 new public
components. It covers date/time input, multi-value selection, transaction
values, async search, file attachments, and semantic form composition.

### Added

- `DatePicker` and `TimeInput` use native browser controls so the user keeps
  their locale and platform conventions.
- `MultiSelect` supports controlled or uncontrolled multiple selections.
- `PercentageInput` and `QuantityInput` build on the numeric input contract
  with meaningful suffixes.
- `AsyncCombobox` loads search results on focus and query changes, with loading,
  empty, and error states.
- `FileUpload` supports selection, removal, type filters, and count/size limits.
- `Form`, `FormActions`, and `Fieldset` provide accessible structure for
  transaction workflows.

### Quality

- 87 unit tests pass.
- Lint, typecheck, package build, and Storybook build pass.
- No breaking changes are introduced in this release.
