# @orizz-rs/ui v0.2.5

## Internal project structure refactor

This release reorganizes the codebase to make the component library easier to
scale without changing consumer imports.

### Changed

- UI primitives remain in `src/components/`.
- Complex reusable patterns now live in `src/compositions/`; `DataTable` is the
  first composition migrated to this layer.
- Added `foundations`, `hooks`, and `utils` layers for future shared code.
- Added an architecture guide and package-root export regression coverage.

### Compatibility

There are no breaking changes. Existing imports remain unchanged:

```tsx
import { Button, DataTable } from '@orizz-rs/ui'
```
